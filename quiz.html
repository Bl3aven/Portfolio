Format du fichier JSON (Quiz)
Champs recommandés (avec valeurs par défaut si absents). Les questions doivent avoir 4 réponses.
Règles :
  • title (string) : défaut “Quiz Live”.
  • description (string) : défaut vide.
  • timeLimit (number) : temps par défaut en secondes (défaut 20).
  • questions[] : liste d’objets question.
  • Dans chaque question : question, answers[4], correctIndex (0..3).
  • weight (number) : pondération (défaut 1). Score final = score Kahoot × weight.
  • explanation (string) : optionnel.
